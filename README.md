# SunChaser: ระบบแผงโซลาร์เซลล์อัจฉริยะ ติดตามดวงอาทิตย์

## สมาชิกในกลุ่ม
1. นายวรัตถดนย์ มูลนาค 68070168
2. นายวศิน เหมือนจิต 68070170
3. นายเอกวริษฐ์ ทองสุขธนไพศาล 68070210
4. นายธนดล เขียวชอุ่ม 68070262

## ภาพรวมโครงการ
SunChaser คือระบบแผงโซลาร์เซลล์ขนาดเล็กที่หมุนตามดวงอาทิตย์ได้โดยอัตโนมัติ ใช้เซนเซอร์ LDR ตรวจจับทิศทางของแสง แล้วสั่งมอเตอร์หมุนแผงให้ตั้งฉากกับแสงอยู่เสมอ พลังงานที่ได้จะถูกชาร์จเข้าแบตเตอรี่เพื่อเป็นไฟสำรอง โดยมอเตอร์ เซนเซอร์ และวงจรควบคุมใช้ไฟจากแบตเตอรี่ของระบบเอง จึงไม่ต้องพึ่งแหล่งไฟภายนอก พร้อมแสดงเปอร์เซ็นต์แบตเตอรี่บนจอ LCD

## จุดประสงค์ของโครงการ
1. สร้างระบบแผงโซลาร์เซลล์ที่หมุนตามดวงอาทิตย์ เพื่อให้แผงรับแสงได้มากกว่าแผงแบบติดตาย
2. เก็บพลังงานไว้ในแบตเตอรี่ เพื่อใช้เป็นไฟสำรอง

## ปัญหาที่โครงการต้องการแก้
แผงโซลาร์เซลล์แบบติดตายอยู่กับที่รับแสงได้ไม่เต็มประสิทธิภาพ เพราะดวงอาทิตย์เคลื่อนที่ตลอดวัน ทำให้มุมตกกระทบระหว่างแสงกับแผงเปลี่ยนไปตลอดเวลา นอกจากนี้ พื้นที่ห่างไกลที่ไม่มีไฟฟ้าก็ยังต้องการแหล่งพลัง

### ความสำคัญของปัญหา
ประเทศไทยมีแสงแดดที่แรงและเหมาะกับการผลิตไฟฟ้าจากพลังงานแสงอาทิตย์ แต่การใช้งานจริงยังไม่คุ้มค่าเต็มที่ หากแผงรับแสงได้มากขึ้น จะช่วยลดการพึ่งพาไฟฟ้าจากโรงไฟฟ้า ลดค่าไฟ และลดมลภาวะต่อสิ่งแวดล้อม

### ผู้ที่ได้รับประโยชน์
บุคคลทั่วไปที่ต้องการใช้งานแผงโซลาร์เซลล์ ผู้ที่ต้องการประหยัดค่าไฟ ผู้ที่อยู่ในพื้นที่ห่างไกลที่ไม่มีไฟฟ้า และผู้ที่ต้องการช่วยลดมลภาวะต่อสิ่งแวดล้อม

## แนวทางการแก้ปัญหา
ใช้เซนเซอร์ตรวจจับทิศทางของแสงอาทิตย์ แล้วสั่งมอเตอร์หมุนแผงให้ตั้งฉากกับแสงอยู่เสมอ พลังงานที่ได้จะถูกชาร์จเข้าแบตเตอรี่เพื่อเป็นไฟสำรอง โดยมอเตอร์ เซนเซอร์ และวงจรควบคุมใช้ไฟจากแบตเตอรี่ของระบบเอง จึงไม่ต้องพึ่งแหล่งไฟภายนอก

ขั้นตอนการทำงาน
1. **ตรวจจับทิศทางแสง:** ใช้ LDR 4 ตัววางเป็นรูปกากบาทที่มุมแผง เปรียบเทียบความสว่างระหว่างด้านซ้าย-ขวา และบน-ล่าง
2. **หมุนแผงตามแสง:** ไมโครคอนโทรลเลอร์ประมวลผลค่าจาก LDR แล้วสั่งเซอร์โวมอเตอร์ 2 ตัวให้หมุนแผงไปยังด้านที่สว่างกว่า
3. **ชาร์จแบตเตอรี่:** พลังงานจากแผงโซลาร์ถูกชาร์จเข้าแบตเตอรี่ผ่านโมดูลชาร์จ
4. **จ่ายไฟให้ตัวเอง:** มอเตอร์ เซนเซอร์ และวงจรควบคุมใช้ไฟจากแบตเตอรี่ของระบบ
5. **แสดงสถานะ:** จอ LCD แสดงเปอร์เซ็นต์แบตเตอรี่

## Input และ Output

**Input**
- แสงอาทิตย์
- พลังงานจากแบตเตอรี่สำหรับขับเคลื่อนเซนเซอร์และมอเตอร์

**Output**
- แบตเตอรี่ถูกชาร์จ
- แผงหมุนหันหาแดดโดยอัตโนมัติ
- แสดงสถานะเปอร์เซ็นต์แบตเตอรี่ (Battery %) บนจอ LCD

## ความน่าสนใจ ความแปลกใหม่ ความพิเศษ และประโยชน์
SunChaser มีความน่าสนใจตรงที่ย่อส่วนแนวคิดแผงโซลาร์ที่หมุนตามดวงอาทิตย์ ซึ่งใช้จริงในโรงไฟฟ้าขนาดใหญ่ ให้คนทั่วไปสร้างและใช้งานเองได้ ความพิเศษคือ ติดตามแดดอัตโนมัติ แบตเตอรี่เก็บไฟ  ประโยชน์คือผู้ใช้ทั่วไปและพื้นที่ห่างไกลมีแหล่งไฟที่ใช้งานได้ในต้นทุนต่ำ ช่วยประหยัดค่าไฟและลดมลภาวะ

## เปรียบเทียบกับโครงการที่มีอยู่แล้ว

### 1. Mount Signal Solar (แคลิฟอร์เนีย, สหรัฐอเมริกา)
โครงการที่คล้ายกับ SunChaser เพราะใช้หลักการเดียวกัน คือหมุนแผงโซลาร์ตามดวงอาทิตย์ แต่เป็นโรงไฟฟ้าใหญ่ ส่วน SunChaser เป็นระบบเล็กที่ใช้เองได้โดยไม่ต้องพึ่งโครงข่ายไฟฟ้า มีแบตเตอรี่ในตัว จึงเหมาะกับผู้ใช้รายย่อยและพื้นที่ห่างไกลมากกว่า เพราะต้นทุนต่ำ

### 2. Arduino Dual-axis Solar Tracker (Electromaker)
โครงงานที่ใช้ LDR 4 ตัวและเซอร์โว 2 ตัวหมุนแผงตามแสงในแบบเดียวกับ SunChaser แต่โครงการนั้นเน้นกลไกการติดตามแสงเป็นหลัก ส่วน SunChaser ต่อยอดโดยเพิ่มแบตเตอรี่เก็บไฟ ระบบจ่ายไฟให้วงจรควบคุมเอง และจอ LCD แสดงเปอร์เซ็นต์แบตเตอรี่

## อุปกรณ์ที่ใช้

**Board:** Arduino UNO / ESP32

**Sensor:** LDR ตรวจจับทิศทางแสง

**Module:** แผงโซลาร์เซลล์, โมดูลชาร์จแบตเตอรี่จากแผงโซลาร์, แบตเตอรี่, เซอร์โวมอเตอร์, จอ LCD

**Library:** Servo.h, LiquidCrystal_I2C

**เครื่องมือ:** เบรดบอร์ดและสายจัมเปอร์
