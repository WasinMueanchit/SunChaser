SunChaser: ระบบแผงโซลาร์เซลล์อัจฉริยะ ติดตามดวงอาทิตย์

บทคัดย่อ

SunChaser เป็นโครงงานแผงโซลาร์เซลล์ขนาดเล็กที่สามารถหมุนตามแสงอาทิตย์ได้เองโดยอัตโนมัติ เพื่อแก้ปัญหาแผงโซลาร์เซลล์แบบเดิมที่ติดตั้งอยู่กับที่ ทำให้รับแสงได้ไม่เต็มที่เมื่อดวงอาทิตย์เคลื่อนที่ตลอดวัน ระบบนี้ทำงานโดยใช้ LDR (Light Dependent Resistor) เปรียบเทียบความสว่างเพื่อสั่งให้เซอร์โวมอเตอร์หมุนแผงหันไปหาทิศทางที่มีแสงมากกว่าอยู่เสมอ นอกจากนี้ พลังงานที่ได้ยังถูกนำไปชาร์จเก็บไว้ในแบตเตอรี่ผ่านแผงโซลาร์เซลล์ และสามารถดึงไฟจากแบตเตอรี่กลับมาเลี้ยงบอร์ด Arduino ได้โดยตรง ทำให้ระบบสามารถทำงานได้ต่อเนื่องด้วยตัวเองโดยไม่ต้องเสียบปลั๊กไฟ พร้อมมีหน้าจอ LCD คอยแสดงผลเปอร์เซ็นต์แบตเตอรี่ที่เหลืออยู่

ภาพรวมโครงการ

SunChaser คือระบบแผงโซลาร์เซลล์ขนาดเล็กที่หมุนตามดวงอาทิตย์ได้โดยอัตโนมัติ ใช้เซนเซอร์ LDR ตรวจจับทิศทางของแสง แล้วสั่งมอเตอร์หมุนแผงให้ตั้งฉากกับแสงอยู่เสมอ พลังงานที่ได้จะถูกชาร์จเข้าแบตเตอรี่เพื่อเป็นไฟสำรอง โดยมอเตอร์ เซนเซอร์ พร้อมแสดงเปอร์เซ็นต์แบตเตอรี่บนจอ LCD

จุดประสงค์ของโครงการ

  1. สร้างระบบแผงโซลาร์เซลล์ที่หมุนตามดวงอาทิตย์ เพื่อให้แผงรับแสงได้มากกว่าแผงแบบติดตาย
  2. เก็บพลังงานไว้ในแบตเตอรี่ เพื่อใช้เป็นไฟสำรอง

ประโยชน์ของโครงการ

โครงงานนี้เป็นประโยชน์ต่อบุคคลทั่วไปที่ต้องการใช้งานแผงโซลาร์เซลล์ ผู้ที่ต้องการประหยัดค่าไฟฟ้า และผู้ที่อาศัยอยู่ในพื้นที่ห่างไกลหรือไม่มีโครงข่ายไฟฟ้าหลัก โดยช่วยให้มีแหล่งพลังงานสำรองขนาดพกพาที่สามารถผลิตและเลี้ยงพลังงานตัวเองได้ มีต้นทุนต่ำ เข้าถึงและสร้างขึ้นเองได้ง่าย และช่วยส่งเสริมการใช้พลังงานสะอาดเพื่อลดมลภาวะต่อสิ่งแวดล้อม

แนวทางการแก้ปัญหาและหลักการทำงานของระบบ

วงจรตรวจจับและขับเคลื่อน

1. การตรวจจับแสงและการสั่งการเซอร์โวมอเตอร์

เซนเซอร์ LDR จะคอยตรวจจับแสง โดยระบบจะปล่อยกระแสไฟเข้าไปผ่าน LDR และวงจรลดแรงดัน จากนั้นนำค่าแรงดันที่แบ่งได้ไปอ่านค่าสัญญาณแอนะล็อกที่ขา A0 และ A1 ของบอร์ด Arduino เพื่อเปรียบเทียบความสว่าง หากด้านใดมีความสว่างมากกว่า ไมโครคอนโทรลเลอร์จะสั่งให้ Servo Motor หมุนหันแผงโซลาร์เซลล์ไปยังด้านที่สว่างกว่านั้นทันที

วงจรพลังงานและชาร์จแบตเตอรี่

2. การชาร์จแบตเตอรี่และการจ่ายไฟเลี้ยงระบบ

ในส่วนของการชาร์จแบตเตอรี่ จะใช้ Solarcell 2 ตัว ต่อแบบอนุกรม เพื่อให้ระดับแรงดัน (Voltage) สูงเพียงพอถึงระดับที่สามารถชาร์จแบตเตอรี่ได้ แล้วต่อกระแสไฟผ่าน Diode เข้าสู่ Battery เพื่อป้องกันไฟไหลย้อนกลับในช่วงที่ไม่มีแดด โดยใช้ถ่าน 2 ตัว ขนาด 3.7V

จากนั้นที่ตัว Battery จะมี โมดูลแปลงแรงดันไฟฟ้าแบบเพิ่มแรงดัน เพื่อยกระดับและควบคุมแรงดันไฟ แล้วต่อด้วย ขั้วต่อกระแสตรงแบบกระบอก สำหรับเสียบใช้งานจ่ายไฟตรงเข้าบอร์ด Arduino ทำให้ระบบสามารถเลี้ยงตัวเองได้

สรุปขั้นตอนการทำงานของระบบ

  1. ตรวจจับทิศทางแสง: ปล่อยไฟผ่าน LDR 2 ตัวและวงจรลดแรงดัน นำไปอ่านค่าแอนะล็อกที่ขา A0 และ A1
  2. ประมวลผลและหมุนแผงตามแสง: เปรียบเทียบค่าความสว่างระหว่างสองด้าน หากด้านใดมากกว่า จะสั่งให้มอเตอร์หมุนแผงหันไปทางด้านนั้น
  3. ผลิตกระแสไฟฟ้าและป้องกันไฟย้อน: ใช้ Solarcell 2 ตัวต่ออนุกรมยกระดับแรงดันให้พอชาร์จแบตเตอรี่ โดยใช้ถ่าน 2 ตัว ขนาด 3.7V และส่งไฟผ่าน Diode ป้องกันไฟไหลย้อนกลับเข้าสู่ Battery
  4. จ่ายไฟกลับมาเลี้ยงระบบ: ดึงไฟจาก Battery ผ่านโมดูลแปลงแรงดันไฟฟ้าแบบเพิ่มแรงดัน แล้วต่อสายผ่านขั้วต่อกระแสตรงแบบกระบอก เสียบเข้าบอร์ด Arduino เพื่อจ่ายไฟเลี้ยงระบบ
  5. แสดงสถานะ: จอ LCD แสดงสถานะการทำงานและระดับเปอร์เซ็นต์ของแบตเตอรี่

Arduino UNO / ESP32

LDR 2 ตัว + วงจรลดแรงดัน
ตรวจจับแสงผ่านวงจรลดแรงดัน แล้วส่งสัญญาณอ่านค่าที่ขา A0 และ A1
Solarcell 2 ตัว (ต่ออนุกรม)
ต่อแบบอนุกรมเพื่อให้ระดับแรงดัน (Volt) สูงเพียงพอต่อการชาร์จแบตเตอรี่
Diode
ต่อคั่นก่อนเข้าแบตเตอรี่ เพื่อป้องกันกระแสไฟฟ้าไหลย้อนกลับในช่วงไม่มีแดด
ถ่านชาร์จ 3.7V จำนวน 2 ตัว
แบตเตอรี่ลิเธียมสำหรับกักเก็บพลังงานไฟฟ้าและจ่ายไฟกลับมาเลี้ยงระบบ
โมดูลแปลงแรงดันไฟฟ้าแบบเพิ่มแรงดัน + ขั้วต่อกระแสตรงแบบกระบอก
วงจรแปลงแรงดันไฟฟ้าแบบเพิ่มแรงดันและขั้วต่อกระแสตรงแบบกระบอก สำหรับเสียบจ่ายไฟเลี้ยงเข้าบอร์ด Arduino
เซอร์โวมอเตอร์
มอเตอร์ขับเคลื่อนสำหรับหมุนปรับองศาของแผงโซลาร์เซลล์ไปยังด้านที่สว่างกว่า
จอ LCD, เบรดบอร์ด, สายจัมเปอร์
จอ LCD I2C แสดงเปอร์เซ็นต์แบตเตอรี่ พร้อมอุปกรณ์ต่อวงจรและไลบรารี Servo.h

Source Code

sunchaser_tracker.ino 
#include <Servo.h>

const int ldrPin1 = A0;
const int ldrPin2 = A1;
const int servoPin = 2;

Servo myServo;

// สำหรับ Continuous Rotation Servo
const int stopSpeed = 90;
const int upSpeed = 180;
const int downSpeed = 0;

const int threshold = 20;

void setup() {
  Serial.begin(9600);
  myServo.attach(servoPin);
  myServo.write(stopSpeed);
}

void loop() {
  int value1 = analogRead(ldrPin1);
  int value2 = analogRead(ldrPin2);

  int difference = value1 - value2;

  Serial.print("LDR1: ");
  Serial.print(value1);
  Serial.print(", LDR2: ");
  Serial.print(value2);
  Serial.print(", Difference: ");
  Serial.println(difference);

  if (difference > threshold) {
    myServo.write(downSpeed);
  }
  else if (difference < -threshold) {
    myServo.write(upSpeed);
  }
  else {
    myServo.write(stopSpeed);
  }

  delay(100);
}
